# ⛵ Saildrone & Conventional Sailboat Dynamics Simulation

Bu proje, otonom kanat yelkenli **Saildrone** ile geleneksel sabit yelkenli katamaran arasındaki aerodinamik manevra kabiliyeti ve hareket özgürlüğünü karşılaştıran 3DOF fizik simülasyonudur.

## 🚀 Özellikler
- **Gerçekçi Aerodinamik Polar:** NACA 0012, NACA 0015 ve Bombeli Kumaş Yelken profilleri.
- **Saildrone Otonom Trim:** Serbest dönen ana kanat ve kuyruk sayesinde her rotada daima en verimli hücum açısı (12°).
- **Klasik Yelken Dinamiği:** Sabit sancak açısı ve rota sapmalarında oluşan bayılma/stall etkisi.
- **Canlı Telemetri:** Mesafe (m), hız (knot) ve verimlilik karşılaştırması.

## 💻 Yerel Çalıştırma
```bash
pip install -r requirements.txt
streamlit run app.py
```
